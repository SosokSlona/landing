3. Оптимизация ClickHouse: схема дедупликации и сжатия

Для эффективного обновления цен на миллионах позиций используется движок `ReplacingMergeTree` с версионированием по метке времени, что исключает блокирующие `UPDATE` операции.

market_lots_schema.sql High Ingestion DDL 
CREATE TABLE market_intelligence.lots (
    lot_id UInt64,
    source_id LowCardinality(String),
    category LowCardinality(String),
    title String,
    price Float64,
    historical_median Float64,
    discount_pct Float32,
    score Float32,
    attributes Map(String, String),
    scraped_at DateTime CODEC(DoubleDelta, ZSTD(1)),
    version UInt64
) ENGINE = ReplacingMergeTree(version)
PRIMARY KEY (category, lot_id)
ORDER BY (category, lot_id, scraped_at)
SETTINGS index_granularity = 8192;

4. Асинхронный воркер и скоринг без задержек

Парсеры написаны на Python 3.12 с использованием `uvloop` и пула сессий `aiohttp`. Скоринг лота опирается на статистические медианы из ClickHouse, кэшированные в памяти Redis, что позволяет рассчитывать скор за менее 0.4 мс на лот.
