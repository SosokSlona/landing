1. Исходная проблема и требования безопасности

Первая линия технической поддержки крупной fintech/B2B-компании тратила свыше 70% времени на типовые вопросы по регламентам, документации и тарифам. При этом действовали жесткие ограничения:

  • Категорический запрет публичных API (OpenAI/Anthropic): коммерческая тайна, клиентские логи и транзакции не имеют права покидать изолированный контур компании.
  • Недопустимость галлюцинаций: ответ модели должен содержать ссылки на актуальные разделы внутренней документации и верифицироваться гардрайлами.
  • Сложная специфика терминологии: чистый векторный поиск (dense embeddings) путал технические артикулы и номера регламентов, требовался гибридный поиск с точным ключевым совпадением (BM25).

3. Ключевые фрагменты реализации

Гибридный поиск в PostgreSQL (pgvector HNSW + Full-Text BM25)

Объединение векторного сходства косинусного расстояния (`<=>`) и полнотекстового ранжирования (`ts_rank_cd`) через алгоритм Reciprocal Rank Fusion (RRF). 

WITH dense_search AS (
    SELECT id, ROW_NUMBER() OVER (ORDER BY embedding <=> $1::vector) AS dense_rank
    FROM knowledge_chunks
    ORDER BY embedding <=> $1::vector
    LIMIT 20
),
sparse_search AS (
    SELECT id, ROW_NUMBER() OVER (ORDER BY ts_rank_cd(fts_vector, plainto_tsquery('russian', $2)) DESC) AS sparse_rank
    FROM knowledge_chunks
    WHERE fts_vector @@ plainto_tsquery('russian', $2)
    LIMIT 20
)
SELECT k.id, k.content, k.source_url,
       COALESCE(1.0 / (60 + d.dense_rank), 0.0) +
       COALESCE(1.0 / (60 + s.sparse_rank), 0.0) AS rrf_score
FROM knowledge_chunks k
LEFT JOIN dense_search d ON k.id = d.id
LEFT JOIN sparse_search s ON k.id = s.id
WHERE d.id IS NOT NULL OR s.id IS NOT NULL
ORDER BY rrf_score DESC
LIMIT 5;

Асинхронная генерация ответа с проверкой фактов (Guardrails)

Потоковый инференс через vLLM с проверкой цитирования источников перед финальной публикацией в тикет-систему. 

async def generate_rag_response(query: str, context_chunks: list[str]) -> str:
    prompt = build_grounded_prompt(query=query, contexts=context_chunks)
    
    async with httpx.AsyncClient(timeout=10.0) as client:
        res = await client.post(
            f"{VLLM_INTERNAL_URL}/v1/chat/completions",
            json={
                "model": "local-mistral-7b-instruct",
                "messages": [{"role": "user", "content": prompt}],
                "temperature": 0.1,
                "max_tokens": 512,
            }
        )
        return res.json()["choices"][0]["message"]["content"]
