1. Исходная проблема и вызовы инфраструктуры

В высоконагруженных B2B-системах подключение клиентов напрямую к инференс-серверам (vLLM / TGI) приводит к фатальным отказам. В отличие от стандартных веб-сервисов, инференс больших языковых моделей обладает критическими свойствами:

  • Ограниченность контекстной памяти (KV Cache): неконтролируемый наплыв параллельных длинных промптов мгновенно приводит к исчерпанию VRAM (CUDA Out Of Memory).
  • Неприменимость классического Rate Limiting (RPS): один запрос на 4,000 токенов нагружает GPU сильнее, чем 100 запросов по 20 токенов. Ограничивать необходимо именно Tokens Per Minute (TPM) и активный KV-cache volume.
  • Потоковая деградация (Streaming SSE): клиенты держат постоянное HTTP-соединение, что при блокирующей архитектуре исчерпывает файловые дескрипторы и пулы потоков.

3. Ключевые компоненты реализации

Атомарный алгоритм Token Bucket на Redis Lua

Скрипт Lua выполняется атомарно внутри инстанса Redis за субмиллисекундное время, резервируя расчетное количество токенов перед отправкой запроса к GPU. 

local key = KEYS[1]
local requested = tonumber(ARGV[1])
local capacity = tonumber(ARGV[2])
local refill_rate = tonumber(ARGV[3])
local now = tonumber(ARGV[4])

local data = redis.call("HMGET", key, "tokens", "last_update")
local tokens = tonumber(data[1]) or capacity
local last_update = tonumber(data[2]) or now

local delta = math.max(0, now - last_update)
tokens = math.min(capacity, tokens + delta * refill_rate)

if tokens >= requested then
    tokens = tokens - requested
    redis.call("HMSET", key, "tokens", tokens, "last_update", now)
    redis.call("EXPIRE", key, 300)
    return {1, tokens}
else
    return {0, tokens}
end

Zero-Allocation SSE Stream Forwarding на Go

Кастомная реализация потоковой передачи Server-Sent Events без лишних аллокаций памяти в куче (heap allocations) позволяет одному узлу шлюза удерживать свыше 8,500 одновременных SSE-соединений. 

func StreamProxy(w http.ResponseWriter, resp *http.Response) error {
    flusher, ok := w.(http.Flusher)
    if !ok {
        return errors.New("streaming not supported")
    }

    w.Header().Set("Content-Type", "text/event-stream")
    w.Header().Set("Cache-Control", "no-cache")
    w.Header().Set("Connection", "keep-alive")
    w.WriteHeader(resp.StatusCode)

    buf := bufPool.Get().([]byte)
    defer bufPool.Put(buf)

    for {
        n, err := resp.Body.Read(buf)
        if n > 0 {
            if _, wErr := w.Write(buf[:n]); wErr != nil {
                return wErr
            }
            flusher.Flush()
        }
        if err != nil {
            if err == io.EOF {
                return nil
            }
            return err
        }
    }
}
