# HTML & CSS Style Guide

## General Principles
- Write semantic, accessible HTML5.
- Use utility-first CSS via Tailwind CSS with consistent color palettes and spacing.
- Ensure 100% responsiveness across mobile (320px+), tablet, and desktop (4K).
- Avoid brittle fixed-width ASCII art in favor of responsive CSS grid cards.
- Adhere strictly to the project's zero-comment rule for markup.
