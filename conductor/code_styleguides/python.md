# Python Style Guide

## General Principles
- Follow PEP 8 guidelines and use static typing (`typing`, `mypy`).
- Prefer modern Python 3.12+ features (type parameter syntax, pattern matching).
- Use `asyncio` and non-blocking I/O for network-bound operations.
- Structure error handling with custom exception hierarchies.
- Ensure strict zero-comments in production files where requested by project standards.
