# Track Specification: FEAT-008

## Title: Interactive Case Playgrounds — ClickHouse ETL Batching & Private RAG Retrieval

### 1. Overview & Context
Добавление интерактивных технических песочниц (Playgrounds) во второй и третий кейсы (а также компактных мини-виджетов на главную страницу в соответствующие карточки). Это превращает кейсы из статического текста в живые инженерные демонстраторы, доказывающие реальный опыт и увеличивающие время удержания и конверсию в B2B-лиды.

### 2. Functional Requirements
- **FR-1: Интерактивный симулятор ETL и ClickHouse (`cases/autonomous-market-intelligence.html`):**
  - Кнопки: «Сбор лотов (1,000 items)», «⚡ Пиковый спайк (10,000 items)», «Сброс».
  - Живые метрики: Total Ingested, ZSTD 6.2x сжатие, Push Latency < 1.2s, Buffer Flush Status.
  - Терминальный лог конвейера с подсветкой этапов.
- **FR-2: Интерактивная песочница Private RAG (`cases/enterprise-rag-automation.html`):**
  - 3 быстрых пресета вопросов + свободный ввод.
  - Визуализация гибридного поиска (BM25 + pgvector HNSW).
  - Верифицированный ответ модели с цитатой документа и индикатором Guardrails.
- **FR-3: Интеграция мини-демо на Главную страницу (`index.html`):**
  - Добавление компактных интерактивных тестов в карточки Кейса #02 и Кейса #03.

### 3. Acceptance Criteria
- [x] Песочницы работают плавно на чистом JS без внешних тяжелых зависимостей.
- [x] Полная адаптивность на смартфонах (320px–430px) без горизонтального скролла.
- [x] Строгое соблюдение политики Zero Comments (0 комментариев в коде).
- [x] Все страницы протестированы и отдают HTTP 200 OK на Cloudflare Pages.
